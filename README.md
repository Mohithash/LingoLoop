# Lingo Loop

**Speak from day one.** A bring‑your‑own‑key AI language tutor.

- 🎭 **Scenes** — café, airport, directions, doctor, job interview, market, hotel, or free chat. The tutor stays in character at your CEFR level (A1–C1).
- ✏️ **Gentle corrections** — every reply shows the corrected version of what you said and a one‑line explanation in your language; tap any tutor bubble to break it down.
- 🃏 **Auto‑deck** — new words from conversations are saved as flashcards with SM‑2 spaced repetition (Again / Hard / Good / Easy).
- 📈 **Progress** — words met, things said, deck maturity, new words per day.
- 14 target languages; any native language.

BYOK: Claude (Anthropic) or any OpenAI‑compatible endpoint. See [PRIVACY.md](PRIVACY.md).
